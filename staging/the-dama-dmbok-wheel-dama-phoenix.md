## The DAMA Wheel: A Blueprint for Modern Data Management

The DAMA Wheel is the iconic visual framework at the heart of the DAMA-DMBOK (Data Management Body of Knowledge). It places Data Governance at the center and surrounds it with the core knowledge areas that define modern data management. These include Data Architecture, Data Modeling and Design, Data Storage and Operations, Data Security, Data Integration and Interoperability, Document and Content Management, Reference and Master Data, Data Warehousing and Business Intelligence, Metadata Management, and Data Quality Management. The Wheel communicates a simple but powerful message. Data Governance holds everything together, and the surrounding disciplines work as interconnected functions rather than isolated silos.

For data professionals, the Wheel serves as both a learning roadmap and a strategic planning tool. It provides a shared vocabulary across teams, helps organizations assess maturity gaps, and guides the design of balanced data programs. The DAMA-DMBOK Version 2 Revised also introduces the Evolved Wheel, which reflects how data management has matured to include emerging areas like ethics, big data, and data science. Together, the original and evolved versions give practitioners a clear picture of how data management responsibilities fit together and how each discipline contributes to building a trusted, well-governed data environment.

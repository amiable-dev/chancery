Quick Start

Your first gated promotion in five minutes: ingest a source, let your agent judge it, and watch the gate hold the corpus honest.

Prerequisites
Node ≥ 22 and a git repo. An agent harness (Claude Code, Copilot, Windsurf, Devin) is optional but the loop is best driven from one — the generated skills teach it everything below.

1 · Clone and verify

Verification is the contract — run it first so you know what green looks like.

$ git clone https://github.com/amiable-dev/swe-ai-ml-kb && cd swe-ai-ml-kb
$ npm install
$ npm run verify   # 480+ files · schema/links/index/cards · ~1s

No API keys, no network: kb verify checks records, it never fetches. Network verbs record evidence; the gate stays hermetic.

2 · Run the loop

Every command that needs judgment runs in two phases — kb never calls a model.

$ kb ingest https://example.com/article      # → staging/<slug>.md, source hashed
$ kb assess staging/<slug>.md                # phase 1 → task.json for YOUR agent
$ kb assess staging/<slug>.md \
     --verdict answer.json                   # phase 2 → validated, applied by rule
$ kb promote <slug> --draft d.json --apply   # → concepts/<slug>.md, by construction
Phase
Who acts
Guarantee
1 · emit
kb writes a self-contained task envelope
rubric routing is a lookup table, not a vibe
judgment
your agent — or a council, or a human
any schema-conforming supplier; never named in canon
2 · apply
kb validates and applies by rule
stale, replayed, out-of-bounds answers refused
Dry-run by default
Everything mutating previews first; --apply requires a clean tree, so every change stays reviewable as a diff. A discard verdict is a recommendation — nothing is auto-deleted.

3 · Ask the corpus

$ kb query "how should agent memory persist?"
3 concepts · ranked · graph edges attached
  1. agent-state              supersedes: agent-scratchpads
  2. agent-memory-lock-in     contrasts-with: portable-skills
  3. agent-checkpoint-resume  depends-on: agent-state

An answer citing a concept that wasn't retrieved is rejected. kb context compiles the exact bundle a task needs — deterministic, budgeted, byte-stable.

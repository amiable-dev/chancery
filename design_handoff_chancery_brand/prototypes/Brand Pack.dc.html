01 — Logo system

Brackets around the corpus

Two brackets — the deterministic gate — hold ragged note lines that consolidate as they descend the family ramp: teal staging in, purple canon out. Same bar language as llm-council, inverted story: the council fragments one answer into voices; kb converges many notes into one governed corpus.

Nodes. White card, 1.5px border in the stage's ramp step, radius 6, mono uppercase kicker + Plex Sans 600 name. Canon nodes fill Purple 600.

08 — MkDocs Material overrides

Drop-in theme for the docs site

site_name: chancery
site_url: https://chancery.dev
theme:
  name: material
  logo: img/logo.svg
  favicon: img/favicon.svg
  font:
    text: IBM Plex Sans
    code: IBM Plex Mono
  palette:
    - scheme: default
      toggle: { icon: material/brightness-7 }
    - scheme: slate
      toggle: { icon: material/brightness-4 }
extra_css:
  - stylesheets/extra.css

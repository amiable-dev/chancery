# Agentic DevOps Maturity Model — Flashcards

#flashcards/devops

## Definition <!-- kb:card:a85f1d -->
What is the Agentic DevOps Maturity Model?
?
A four-level framework for assessing an engineering organisation's readiness to operate AI agents as regular code contributors, evaluated across four dimensions: Foundations, Agent Adoption, Pipeline Maturity, and Governance.

## Levels <!-- kb:card:696d1f -->
What are the four levels of the Agentic DevOps Maturity Model?
?
1. **Reactive** — manual processes, ad hoc AI use, no governance
2. **Foundation** — automated CI/CD, IaC, shared instruction files, basic policies
3. **Structured** — spec-driven development, custom agents with attribution, formal governance
4. **Optimized** — living specs, adaptive verification, attestation standards, continuous compliance

## Core Principle <!-- kb:card:fe7784 -->
What is the core insight behind "agents are accelerators"?
?
Agents accelerate whatever system they operate within — healthy or broken. If CI/CD is fragile, agents break it faster. If test coverage is thin, agents ship untested code at higher velocity. Fix the foundations before scaling agent adoption.

## Leverage Point <!-- kb:card:d26699 -->
What is the highest-leverage move for a Level 1 organisation?
?
Not to adopt more agents — but to invest in the six DevOps foundations (CI/CD automation, automated testing, IaC, security scanning, branch protection, observability) that make agents safe and effective to adopt.

## Transition <!-- kb:card:301dd9 -->
What is the key investment for the Level 2 → 3 transition?
?
Specification-driven development and rich repository skill profiles — moving from shared instruction files to versioned specs with acceptance criteria and custom agents with attribution metadata.

## Four Dimensions <!-- kb:card:2c9723 -->
What four dimensions does each maturity level evaluate?
?
Foundations, Agent Adoption, Pipeline Maturity, and Governance — each must be assessed independently; strong pipelines without foundations create a false sense of readiness.

## Context

A critical comparison against NanoNets/Graft (2026-08-24) found a convergent body plan — markdown + wikilinks + typed links + content hashes + a deterministic CLI holding no model key + MCP + generated agent adapters — built on the opposite ontology: Graft's graph is a **cache** over a rebuildable source of truth (the code); Chancery's corpus is a **record** with no source of truth to rebuild from. Nothing in Graft substitutes for the gate; several mechanisms transfer. Council packet 7 reviewed the first draft adversarially; every decision below carries its amendments. Decisions carry individual status so any one can be superseded without disturbing the rest. Issues #3–#8 plus the D7–D9 issues track execution.

## Decisions

**D1 — Retrieval architecture** *(status: accepted; supersedable independently).* When SCOPE's search tripwire arms, `kb query` adopts **lexical seed + deterministic typed graph expansion with retained paths** — no embeddings, no model, no network in the read path, and every ranked answer explainable as "seeds matched → path taken → edge types traversed." The rank function itself is **not fixed here**: it is a pre-registered bake-off adjudicated by the D2 harness — (1) lexical-only + alias table (D9) as the null hypothesis any graph stage must beat, (2) field-weighted BM25 + bounded k-hop typed decay, (3) typed spreading activation, (4) typed/directed personalized PageRank with pinned iteration count, canonical summation, and ID tie-breaks. Simplest-within-declared-tolerance wins. Constraints regardless of winner: per-type edge weights are **declared, versioned, diffable data**; traversal follows stored link direction only; reciprocal-rank fusion with the lexical channel so graph rank can never fully swamp a correct-but-orphaned lexical hit; a "no free hubs" rule (promotion into results requires a lexical or edge-clause match); refutation-carrying edges surfaced as such, never ranked as support. *Packet-7 rationale for not fixing an algorithm:* vanilla PPR's out-degree normalization inverts curatorial signal, flattens edge types, and mixes past a 212-node graph's diameter at standard damping — and the instrument that should decide (D2) is built first by this ADR's own ordering.

**D2 — The query eval set** *(status: accepted; build first).* Built now, per the corpus's own `golden-dataset-retrieval-evals` concept, amended by packet 7: **pooled/graded qrels** over the union of all challengers' outputs (required-concept labels alone cannot compute precision); every query carries a **provenance field** (council packet, issue thread, external reader, log-derived) with metrics reported split by class and corpus-synthesized queries discounted; a mandatory **vocabulary-mismatch subset** (queries sharing little lexical overlap with their required concepts — the entire justification for a graph stage); labels routed through the ADR-010 two-phase machinery so the log proves each label predates the ranker commit, with **`label-edits-after-failure`** tracked as the gaming detector; a sealed holdout never used for tuning; anti-labels ("must not return") and no-answer queries; a label-staleness policy (corpus-version-at-labeling); a declared noise band and per-item diffs rather than scalar deltas. **Posture:** score metrics non-gating; **hygiene gates immediately** (schema validity, unique IDs, deterministic cross-platform execution, tracked results artifact). Promotion to score-gating requires all five pre-declared triggers: ≥50 items with ≥50% external provenance across ≥2 authors; pooled labels adequate for the gated metric; an established noise band; one demonstrated true-positive red; baseline stability across substantive corpus revisions — then gating is a ratchet on the sealed subset with a logged waiver path. The SCOPE tripwire is reworded to key on *substantive change* (corpus revision, query cohort, ranker) against a pinned baseline, not elapsed time. **The eval-set spec returns through council (packet 8) before the D1 tripwire can fire.**

**D3 — Crux excerpts** *(status: accepted; supersedable independently).* An optional per-source verbatim excerpt captured when the source is judged. Amended terms: stored as a **content-addressed object** in the evidence store (frontmatter holds pointer + `crux_hash`, `crux_source_hash`, `crux_captured_at`, `crux_locator`); **capture-time substring-containment validation** — the proposed crux must be a byte-substring of the just-fetched source, checked by rule in the proposing command, because a model supplier paraphrasing a "verbatim" passage is otherwise uncatchable. **Honest bound, stated plainly:** the C5 store retains hashes, not bytes, so containment cannot be re-checked offline — survivability of the excerpt is real, re-verifiability of its verbatimness is capture-time only. `kb verify` computes a tri-state per crux: **verified** (source hash unchanged), **unverifiable** (dead), **contested** (source drifted, crux not re-confirmed); re-fetches append verification events and never overwrite. A crux **never upgrades** a citation's verification status, and `kb support` distinguishes bound-to-stored-excerpt from bound-to-live-source. Copyright posture: 500 characters is a **ceiling, not a safe harbor** — the load-bearing passage is by construction the heart of the work — so: per-source license enum including `withheld-license` (locator + hash, no text; the default for paywalled/contract-bound material), a lesser-of proportionality floor for short works, a **per-work aggregate cap enforced by `kb verify`**, contiguous spans only, attribution wherever an excerpt renders. Schema change ⇒ versioned migration.

**D4 — Provenance-graded rendering** *(status: accepted).* Renamed from "trust-graded": supplier class is a provenance axis, not a quality axis. Exports render **exceptions against a declared house norm** (human-judged, current, no override), not a badge per state; one idiom per axis, accessible text + machine-readable attribute, full detail on drill-down. Grades are computed at export-build time from records, never hand-authored. Supplier class is immutable once logged; overrides layer (dated) rather than rewrite, so overriding can never launder model output into apparent human provenance.

**D5 — Evidence freshness at answer time** *(status: accepted).* Renamed from "evidence age": `kb query` answers carry per-citation **"last checked"** state — hash-unchanged-since-D / re-read-at-D / crux-captured-at-D / **unverifiable-since-D** — plus a per-source `recheck_after` rendered fresh/due/overdue, exact dates on demand, no thresholds or colour on raw day counts (check-recency is not validity; volatility varies per source). **Hard requirement before shipping: the clock is pinned** (`KB_NOW` or commit-derived) and freshness output is excluded from the D2 eval diff — otherwise a deterministic harness flaps daily.

**D6 — SCOPE additions** *(status: accepted).* `kb viz --export` enters SCOPE as a tripwire armed by a **countable** condition: ≥2 distinct external requests recorded as issues, or selection by the #1 queue-visualisation review. The staleness counter's drift predicate must be defined before the counter means anything. Crux excerpts are **excluded by default** from any single-file export (a bundled compilation of third-party quotations is a different copyright posture than a repo).

**D7 — `kb suggest-links`** *(status: accepted; new, per council).* Offline, non-gating, out-of-read-path model-assisted proposal of candidate typed links, flowing through the ADR-010 two-phase machinery for human judgment. Attacks the corpus's real weakness — link recall, the unknown-unknown pairs hand curation never notices — without putting a model in the read path.

**D8 — Record/derivation separation** *(status: accepted; new, per council).* All derived artifacts (adjacency, backlink index, lexical tables, rank results, doc-site, eval outputs) live in a git-ignored cache keyed by corpus content-hash + schema version + tool version + ranking-policy hash: never authoritative, never hand-edited, refusing to serve on key mismatch — and **`rebuild == cached` joins `kb verify`** as an executable determinism test. This is the transferable half of Graft's regenerate-don't-govern model, which the first draft dismissed as category mismatch too quickly; it is also the instrument that pins down any rank stage's numerical determinism.

**D9 — Alias table** *(status: accepted; new, per council).* A curated alias/abbreviation table as versioned corpus data — deterministic, diffable, reviewable. At 212–2,000 notes, seed quality dominates walker choice; this is the highest-leverage retrieval investment and the null-hypothesis baseline for D1's bake-off.

## Execution order

D2 (instrument, spec through packet 8) → D8 (derivation cache — determinism instrument) → D9 (alias table) → D4 → D3 → D5 → D6 (SCOPE edits, immediate) → D7 → D1 (build only when its re-worded tripwire fires, adjudicated by D2). Each build item: spec → TDD → gate.

## Consequences

- Retrieval stays deterministic and **explainable** end-to-end; the rank function is chosen by measurement, not by import; and the determinism claim becomes an executable check (D8) rather than an assertion.
- On embeddings, the position of record, narrowed per packet 7: what is excluded is **third-party neural embeddings in the production read path**, and the ground is a governing **value** — no model artifact in the read path — not a claim that embeddings are nondeterministic (pinned artifacts are versioned, which this project governs well). Corpus-derived deterministic factorizations (LSA, random projection) are not categorically rejected. A pinned embedding baseline is admissible **offline as a benchmark challenger**: if it materially beats lexical+graph on the vocabulary-mismatch subset, that is evidence of a corpus blind spot — routed to D7, not to the read path. The asymmetry with ADR-010 (models may write content into the record but not rank it at read time) is deliberate: written content passes through judgment and the gate; a read-path ranker's influence would be exercised at the moment of use, ungated.
- The evidence ledger gains bounded survivability (crux) with its verification limits stated rather than implied; renders gain legibility without asserting trust the records don't license.
- Not adopted, on the record: Graft's regenerate-don't-govern ontology for the corpus itself (nothing here is regenerable), and any in-CLI model execution however local (the contract is "never calls a model," not "never calls a remote model").
